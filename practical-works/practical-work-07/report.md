# Отчёт о самостоятельной работе № 7

## Проверка прототипа и доработка

**Команда:** «Не баг, а фича», бригада № 1.  
**Тема проекта:** № 16. Помощник по выбору ноутбука для обучения.

Работа запланирована. Результаты заполняются после выполнения задания.

## Цель работы

Проверить прототип помощника по выбору ноутбука для обучения с участием пользователей и улучшить его по результатам обратной связи.

## Задание

1. Показать прототип нескольким людям: сокурсникам, друзьям, по возможности представителям целевой аудитории.
2. Собрать замечания и пожелания.
3. Выделить основные недостатки и предложения по улучшению.
4. Внести доработки в прототип.
