# Отчёт о самостоятельной работе № 3

## Определение целевой аудитории

**Команда:** «Не баг, а фича», бригада № 1.  
**Тема проекта:** № 16. Помощник по выбору ноутбука для обучения.

Работа запланирована. Результаты заполняются после выполнения задания.

## Цель работы

Определить, для кого создаётся помощник по выбору ноутбука для обучения, и описать потребности его пользователей.

## Задание

1. Выделить 1–3 сегмента пользователей.
2. Для каждого сегмента указать возраст, уровень владения техникой, контекст использования, потребности и проблемы.
3. Сформулировать портрет пользователя для каждого сегмента.
4. Согласовать единое видение целевой аудитории в команде.
