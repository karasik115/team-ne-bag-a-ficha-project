# Отчёт о самостоятельной работе № 6

## Разработка прототипа

**Команда:** «Не баг, а фича», бригада № 1.  
**Тема проекта:** № 16. Помощник по выбору ноутбука для обучения.

Работа запланирована. Результаты заполняются после выполнения задания.

## Цель работы

Создать работающий прототип веб-сайта «Помощник по выбору ноутбука для обучения» на основе интерфейса из СР5 и требований из СР4.

## Задание

1. Выбрать инструмент для создания прототипа.
2. Реализовать экраны, спроектированные в СР5.
3. Обеспечить переходы между экранами.
4. Проверить выполнение основных функций из СР4.
5. Разместить прототип или его материалы в репозитории.
