# Матрица RACI

**Команда:** «Не баг, а фича»

Шаблон для заполнения по задачам проекта и согласования командой.

- **R (Responsible):** выполняет задачу.
- **A (Accountable):** отвечает за итоговый результат. Для каждой задачи указать одного A.
- **C (Consulted):** консультирует по задаче.
- **I (Informed):** получает информацию о ходе и результате.
